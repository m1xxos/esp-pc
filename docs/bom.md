# BOM

## Core electronics

- 1x Seeed Studio XIAO ESP32C6
- 3x Optocoupler (example: TLP181 or 4N35)
- 3x 220R resistor (input LED current limit)
- 3x 1k resistor (signal conditioning, if required by module)
- 2x 10k resistor (pull-up / divider in bench harness)
- 2x 100nF ceramic capacitor
- 1x Prototype board or breadboard
- Dupont wires and front-panel splitter leads

## Optional tools

- USB logic analyzer or oscilloscope
- Multimeter
- Heat-shrink and cable sleeve for final install

## Notes

- Prefer optocoupler modules rated for at least 3 kV isolation.
- Do not skip current-limiting resistors.
